## 1. 서론

### 1.1 문서 목적 및 범위
본 문서의 목적은 사용자가 자신의 수입과 지출을 수동으로 기록하고 관리하는 모바일 앱 '머니로그(MoneyLog)' 프로젝트에 대한 테스팅을 수행하고 그 결과를 나타내는 데에 있다. 본 문서에서는 위 프로젝트의 테스트 기준, 테스트 범위, 테스트 케이스와 테스트 결과를 명시한다.

### 1.2 프로젝트 개요
개인이 매일의 수입과 지출을 빠르게 기록하고 확인하기 위한 모바일 앱 시스템을 구축한다. 복잡한 외부 은행 연동 없이 오직 사용자 기기 내부에만 데이터를 저장하여 개인정보를 완벽히 보호하는 기능적 특성이 정상적으로 작동하는지 검증한다.

### 1.3 용어 정의
| 용어 | 설명 |
| :--- | :--- |
| **로컬 DB** | 외부 클라우드가 아닌 사용자 스마트폰 내부 저장소에 구축하는 데이터베이스 시스템 (SQLite). |
| **수동 입력** | 외부 금융기관 API 연동 없이 사용자가 직접 금액과 날짜를 기입하는 방식. |
| **오프라인 우선** | 서버 통신을 배제하여 네트워크가 없는 환경에서도 완벽하게 동작하는 시스템 환경. |

## 2. 테스트 개요

### 2.1 테스트 범위
테스트는 시스템 내부를 모른다는 가정 하에 블랙박스 테스트로 이루어진다. 테스트의 범위는 아래와 같다.

| 범위 | 내용 |
| :--- | :--- |
| **Android / iOS 기반 앱 시스템** | I. 사용자 인터페이스(UI) 동작 정확성 확인<br>II. 요구사항 분석서 기능 충족 확인 |
| **Local Database (SQLite)** | I. 데이터 입출력 및 정합성 연동 시험<br>II. 데이터 무결성 및 단 1원의 오차도 없는 정산 로직 확인 |

### 2.2 테스트 항목 및 통과 기준

| 기능별 테스트 항목  | 통과 기준 |
| :--- | :--- |
| **지출/수입 내역 입력** | 필수 항목(금액, 날짜, 카테고리)을 모두 기입해야 정상적으로 로컬 DB에 저장된다. |
| **내역 조회 및 필터링** | 선택한 날짜 범위나 특정 카테고리에 부합하는 내역만 오차 없이 필터링되어 리스트로 출력된다. |
| **월간 요약 리포트** | 한 달 동안의 총 수입/지출 데이터가 합산되며, 금액 오류 없이 차트와 함께 시각화된다. |
| **카테고리 커스터마이징** | 사용자가 새롭게 추가하거나 수정한 카테고리 명칭이 앱 전반에 즉시 반영된다. |
| **예산 설정 및 알림** | 누적 지출액이 사용자가 설정한 월 목표 예산을 초과하는 즉시 경고 알림 팝업이 출력된다. |

| 비기능별 테스트 항목 | 통과 기준 |
| :--- | :--- |
| **오프라인 환경 작동** | 네트워크를 완전히 차단한 상태(비행기 모드)에서도 모든 기능이 지연 없이 작동한다. |
| **기기 저장소 예외 처리** | 기기 내 남은 용량이 50MB 이하일 경우, 데이터 저장 전 경고 메시지가 정상 출력된다. |

## 3. 테스트 케이스

### 3.1 테스트 케이스 선정
테스트 케이스는 요구사항 분석서의 기능별 테스트 항목에 따라 선정하였으며, 블랙박스 테스트 기법을 기반으로 하여 시스템 내부 확인을 하지 않는 사용자 시점 테스트 케이스 선정에 중점을 둔다.

### 3.2 테스트 케이스 유형
* 금액 및 텍스트 입력을 수행하기 위한 UI 데이터 입력 테스트 케이스
* 예산 초과 및 필수값 누락에 대응하는 예외 처리 동작 테스트 케이스
* 오프라인 상태 및 저장소 용량 한계 상황을 모사한 환경 테스트 케이스

### 3.3 테스트 케이스 목록

**3.3.1 지출/수입 내역 입력 기능**
| Case | 내용 | 입력값 예시 | 예상 결과값 |
| :--- | :--- | :--- | :--- |
| **T1** | 모든 필수 항목 정상 입력 시 데이터가 저장되는가? | 금액: 5000, 타입: 지출, 카테고리: 식비 | SUCCESS (저장 및 메인 화면 이동) |
| **T2** | 필수 항목(카테고리) 누락 시 저장이 차단되는가? | 금액: 10000, 타입: 지출, 카테고리: 선택안함 | FAIL (경고 메시지 출력) |

**3.3.2 내역 조회 및 월간 리포트 기능**
| Case | 내용 | 예상 결과값 |
| :--- | :--- | :--- |
| **T3** | '교통비' 카테고리 필터 적용 시 해당 내역만 출력되는가? | YES |
| **T4** | 입력된 데이터들의 합산이 1원의 오차 없이 정확히 계산되는가? | YES |
| **T5** | 조회 화면의 통계 차트가 입력된 데이터 비중에 맞게 렌더링되는가? | YES |

**3.3.3 카테고리 및 예산 알림 기능**
| Case | 내용 | 예상 결과값 |
| :--- | :--- | :--- |
| **T6** | 새로운 카테고리명('OTT 구독') 추가 후 입력 화면에서 선택 가능한가? | YES |
| **T7** | 이번 달 예산을 50만원으로 설정 후, 누적 지출 51만원이 되는 입력을 시도할 때 경고 팝업이 출력되는가? | YES |

**3.3.4 환경 및 비기능 테스트**
| Case | 내용 | 예상 결과값 |
| :--- | :--- | :--- |
| **T8** | 기기의 와이파이/데이터를 차단한 오프라인 상태에서 앱 구동 및 저장이 정상적으로 동작하는가? | YES |
| **T9** | 기기 잔여 용량이 50MB 이하일 때 저장 경고 메시지가 출력되는가? | YES |
